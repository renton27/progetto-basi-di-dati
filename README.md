# progetto-basi-di-dati
# Database Management System

## Descrizione

Progetto realizzato per il corso di Basi di Dati della Laurea Triennale in Statistica Gestionale presso Sapienza Università di Roma insieme ad alcuni miei colleghi.

Il progetto comprende la progettazione concettuale e logica di un database relazionale, la sua implementazione mediante MySQL Workbench e lo sviluppo di un interfaccia grafica in Python per la gestione e l'interrogazione dei dati.
In questo progetto viene esaminata la gestione dei guasti e la loro relativa risoluzione delle linee telefoniche di Telecom.

## linguaggi utilizzati

- Python
- SQL (MySQL Workbench)
  
## Competenze acquisite

- Progettazione di database relazionali
- Modellazione entità-relazione (modello E-R)
- Linguaggio SQL
- Gestione dei dati
- Sviluppo di interfaccia grafica con Python
